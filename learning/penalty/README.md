# 点球落点预测

页面使用 UPC 2026 Problem B 论文的 v3 全锚点 Wiener-ResMDN。输入固定起点和
0.05 s、0.10 s 的球心坐标，浏览器计算 x = 11 m 平面上的穿越点密度、
众数、均值、50% / 95% 预测区域和条件门内概率。

## 推理与权重

- `app.js` 按 `code/model/train_wiener_mdn.py` 计算 22 维特征和 Wiener 锚点，
  执行输入投影、两个 192 单元的残差块及五分量高斯混合输出。
- `model.json` 记录 seed 11、42、155 的检查点 SHA-256、特征标准化参数、校准表和权重布局。
  `weights.bin` 保存三个检查点的 256,410 个 float32 参数，共 1,025,640 字节。
- 单种子使用训练后的尺度与 HDR 质量阈值。三种子平均等权合并 15 个已缩放分量，
  取混合分布 50% / 95% 的概率质量。
- 门内概率条件为触地前越过门线，判定矩形为 |Y| ≤ 3.55 m、0.11 ≤ Z ≤ 2.33 m。

## 论文案例

seed 11、5 mm、r(0.05) = (1.50, 0.45, 0.44)、r(0.10) = (2.96, 0.86, 0.74)。

| 指标 | 论文诊断结果 |
|---|---|
| 众数 (Y, Z) | (2.666, 1.792) m |
| 分布均值 | (2.711, 1.859) m |
| 50% / 95% 区域 | 0.106 / 0.619 m² |
| 条件门内概率 | 97.7% |
| 恒加速度基线 | (2.495, 1.920) m |

参考值来自 `experiments/diagnostics/diagnostics.json`。网页按画布网格计算等值线面积，
与论文 1201 × 1201 网格的结果可能有轻微差别。

## 本地维护

在 `site` 根目录运行以下命令，然后访问 `http://127.0.0.1:8766/learning/penalty/`。

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

如需从同架构检查点重新导出，在可导入 NumPy 与 PyTorch 的环境中运行：

```powershell
python learning/penalty/export_model.py "E:/SJTU2026/threebody/UPC155"
```

导出会核对 `experiments/main_v3_all` 中各检查点的哈希。模型更新后应同步提升
导出器、`app.js` 和 HTML 脚本地址里的版本标记。旧版分享链接的坐标和噪声仍可读，
已移除的 seed 22 / 33 回退到 seed 11。
