PENALTY FORECAST / 点球落点预测

三个点，猜一个落点。

罚球飞过 0.1 秒，留下的只是两个观测位置。把它们交给论文里冻结的那个混合密度网络，它会给出球门平面上的概率热力图：最可能从哪里穿过、五成与九成的概率区有多大、有多大概率落在门框里。

单位 m · 坐标系：罚球点为原点，x 指向球门，z 向上
球心坐标t = 0 / 0.05 / 0.10 s
xyz r(0)固定 000.11

起点 r(0) 由题目固定为球心 (0, 0, 0.11)。网络以它为已知量，改动起点需要重训模型。

位置噪声 σ
训练种子
样例

网络看到的 11 个特征
特征数值训练集 |z|

特征由三个点作差分得到：中点速度、二阶差分加速度、速率、气动加速度的切向分量与法向模、恒加速度过门时间，再加 σ。上表右侧是该特征的训练集标准化偏差 |z|，超过 3 即明显外推。

METHOD / 这个图是怎么来的

一个网络，十一个数，三个高斯。

网络

输入 11 维：中点速度三分量、二阶差分加速度三分量、速率、气动加速度的切向分量与法向模、恒加速度过门时间、噪声 σ。三个 128 单元的隐藏层，LayerNorm + GELU，输出 3 个带相关系数的二维高斯（混合密度网络），直接预测过门坐标。

数据

物理模拟器（重力 + 二次阻力 + 横向马格努斯力，RK4）生成 50,000 条罚球，其中 41,733 条在空中越过 x = 11 m。按整条轨迹划分出 33,367 条训练样本；每轮给两个观测点叠加 1–20 mm 的独立高斯噪声，并把这个 σ 一并喂给网络。

校准

在独立校准折上为每个噪声档拟合一个标准差缩放系数，再用真值的密度秩修正 50% / 95% 区域的阈值。本页显示的密度、区域与概率都已带上该校准。

局限

全部是仿真结果：先验里的初速、自旋与阻力系数并非真实罚球分布，也没有做过实测标定。图中的“入门概率”以“球已经在空中越过该平面”为前提，只算球心是否落在 3.66 × 2.44 m 的矩形内，与真实进球率不是一回事。

权重取自带冻结校验的 P1 模型（三个训练种子，phys_reduced_k3_*），在浏览器里用 32 位浮点重算，与论文 student-c/P1/final/case.json 的题面案例一致：5 mm 时众数 (2.62, 2.15) m、区域 0.177 / 0.775 m²、入门概率 97.3%。页内区域面积用行进方格法在细网格上重新积分，与论文表格相差约 1%。
