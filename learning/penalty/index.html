PENALTY FORECAST / 点球落点预测

两次观测，预测点球过线位置。

给定罚球起点和前 0.1 秒的两个球心坐标，论文的 v3 Wiener 残差混合密度网络会估计球最可能从哪里穿过门线，以及预测有多不确定。计算在浏览器内完成。

观测输入

单位 m · 坐标系：罚球点为原点，x 指向球门，z 向上
球心坐标t = 0 / 0.05 / 0.10 s
xyz r(0)固定 000.11

起点 r(0) 由题目固定为球心 (0, 0, 0.11)。网络以它为已知量，改动起点需要重训模型。

METHOD / 这个图是怎么来的

从物理外推到五个高斯分量

网络

22 个特征经标准化后进入宽度为 192 的输入投影和两个残差块。网络输出五个相关二维高斯分量的权重、均值偏移和协方差。均值偏移加到按噪声加权的 Wiener 外推锚点上。

数据

v3 结合均匀采样与实测轨迹锚点，用重力、二次阻力和 Magnus 力模拟 1,225,000 次发射。1,091,052 条轨迹在触地前越过门线，其中 872,841 条用于训练、109,108 条独立留作测试。训练时逐轮抽取 1–18 mm 坐标噪声。

校准

每个训练种子分别在独立仿真校准集上调整四档噪声的预测尺度和区域阈值。三种子平均是演示选项，等权合并 15 个分量，轮廓取其 50% / 95% 概率质量，覆盖率未经独立校准。

适用范围

页面使用论文的空中过线主模型。门内概率假设球在触地前已穿过 x = 11 m，计算球心落在 |Y| ≤ 3.55 m、0.11 ≤ Z ≤ 2.33 m 的概率。模型省略门柱碰撞与守门员动作。真实点球的预测区域覆盖率仍待验证。

默认使用论文案例的 seed 11、5 mm。论文报告众数 (2.67, 1.79) m，50% / 95% 区域面积 0.106 / 0.619 m²，条件门内概率 97.7%。网页按画布网格重算等值线与面积，末位可能随画布大小略有变化。
