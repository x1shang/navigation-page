01 / UNIT CIRCLE

单位圆里的六个函数

x² + y² = 1

P = (cos θ, sin θ)；射线与 x = 1 交于 T，与 y = 1 交于 U。OT = sec θ，OU = csc θ；竖直线段是 tan θ，水平线段是 cot θ。本图演示第一象限。

02 / UNIT HYPERBOLA

双曲线上的 cosh 与 sinh

x² − y² = 1

P = (cosh t, sinh t) 始终满足 x² − y² = 1。阴影沿真实曲线围成，有向面积为 t/2。t 是双曲角，不是普通的圆心角。

把关系连起来：倒数、反函数与平方恒等式 ＋

倒数 ≠ 反函数

sec x = 1/cos x
csc x = 1/sin x
cot x = cos x/sin x

反函数交换 x、y。打开图上的「对照反函数」，看主值分支如何关于 y = x 对称。

圆与双曲线

sin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = csc²x

cosh²x − sinh²x = 1
1 − tanh²x = sech²x
coth²x − 1 = csch²x

主值与记号

arccot x 取 (0, π)。
arcsec x = arccos(1/x)。
arccsc x = arcsin(1/x)。

arsinh / arcosh / artanh 也常写作 arcsinh / arccosh / arctanh。不连通定义域的各分支可有独立积分常数。
