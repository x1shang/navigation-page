COLOR REFERENCE / 颜色参考

给颜色，一个名字。

从常用色中寻找灵感，也可以自己调出喜欢的颜色。

01 / COLOR PALETTE

常用色卡

颜色相同，表达方式可以不同。选择格式，查看每个色块对应的值。

名称与色值参考 Python Turtle 使用的 Tk 颜色表；同名颜色在其他标准中可能不同。

02 / MIX YOUR OWN

自选颜色

选取颜色或输入十六进制色值，下方跟随上面的格式同步变化。

输入 6 位十六进制色值，如 #9B87F5。

Turtle 颜色名称

自选颜色仅在与常用色卡中的颜色完全一致时显示名称；其余显示“无匹配名称”。
